Edit Skedz locally

Open the editor, select Work with Local Repository, and share the project folder where package.json is located. No login is required.

Content editorPreview website

Workflow

  1. Save locally with Save and check the preview.
  2. Exit the editor after saving with Ctrl+C in the terminal.
  3. Execute npm run build to generate finished files without upload.
  4. Execute npm run deploy to upload the finished files to the live website.

Note: Before running npm run deploy, you have to set up SFTP or FTPS access. Making a backup of an already existing live website is recommended. Saving, previewing, and building do not publish anything.

### Supported formats

Skedz reads several common formats used by conferences and tools:

- **JSON** – Frab / Pretalx `schedule.json`
- **XML** – Pentabarf / Frab / Pretalx `schedule.xml`
- **xCal** – XML iCalendar format
- **iCal / ICS** – standard iCalendar format

### Example schedules

A few real-world examples that work out of the box:

- **39C3 (Chaos Communication Congress)**\
  [JSON (`schedule.json`)](https://app.skedz.org/?url=https://api.events.ccc.de/congress/2025/schedule.json)

- **FOSDEM 2026**\
